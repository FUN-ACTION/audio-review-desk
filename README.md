# Audio Review Desk

在本机整理和审核音频素材。导入文件、文件夹或清单，逐条试听，记录评分、问题、保留区间和时间批注，再导出 CSV 或 JSON。

[English](docs/README.en.md) · [安装](docs/installation.md) · [清单格式](docs/manifests.md) · [版本记录](docs/releases/README.md)

[项目网站](https://fun-action.github.io/audio-review-desk/tour/) · [下载](https://github.com/FUN-ACTION/audio-review-desk/releases/latest)

## 运行方式

- **本地工作台**：在自己的电脑上启动服务，用浏览器听审。支持 Windows、macOS 和 Linux，需要 Python 3.11 或更新版本。
- **项目网站**：可以体验 A/B 切换、区间循环和时间批注。网页示例使用合成音频，批注刷新后清除；正式审核记录保存在本地工作台。
- **交付内容**：当前版本提供源码包和 Python wheel，需要按安装说明准备 Python 环境，没有独立的桌面安装程序。

## 开始使用

Windows：下载并解压[最新源码包](https://github.com/FUN-ACTION/audio-review-desk/releases/latest)，双击 `start-windows.cmd`。需要 Python 3.11 或更新版本。

macOS / Linux：

```sh
git clone https://github.com/FUN-ACTION/audio-review-desk.git
cd audio-review-desk
python3 -m venv .venv
.venv/bin/python -m pip install .
.venv/bin/python -m audio_review_desk init --workspace review-workspace
.venv/bin/python -m audio_review_desk serve --workspace review-workspace --open
```

打开后选择音频文件、文件夹，或 CSV / JSON 清单。可以一次选择多个文件。普通 PCM WAV 直接可用；其他格式需要 [FFmpeg 与 ffprobe](docs/installation.md#optional-ffmpeg)。

快捷选择文件、文件夹或清单采用追加导入。失败后转入手动重试时仍保持追加；已选路径会保留，未选到新路径则需重新填写。手动窗口内主动设置的替换模式不受影响，导入写入请求不会自动重发。

导入期间可以取消。取消完成后，之前的素材列表和已保存的审核记录保持不变；进入保存阶段后不再接受取消。

导入状态及完成后的清单读取遇到临时连接错误会自动重试。新的编辑、选择或保存会停止旧清单的重试，避免覆盖当前工作。

还没有素材时，可以先用生成的示例音频熟悉流程。在**新的空工作区**中运行以下 macOS / Linux 命令；Windows 将 `.venv/bin/python` 换成 `.venv\Scripts\python.exe`：

```sh
.venv/bin/python -m audio_review_desk demo --workspace demo-workspace
.venv/bin/python -m audio_review_desk serve --workspace demo-workspace --open
```

试听一条音频，保存决定，再导出记录。示例包含重复、静音和无法解码的条目，用于展示不同审核状态；不需要提供私人录音。

## 听审

搜索可匹配文件名、备注和时间批注。匹配已保存备注或批注时，结果会显示一段限长原文及批注时间，帮助区分同名音频；默认列表和仅文件名命中保持简洁。摘要只在本机已有审核界面显示，不包含未保存编辑，也不会自动跳转播放。按 Ctrl / ⌘ K 可以查找音频或执行常用操作。命令面板打开期间若素材库更新，选择结果时会使用最新记录；已移除的条目只显示提示，不改变当前草稿。

| 操作 | 用法 |
| --- | --- |
| 对照试听 | 切换 A / B，比较原音频和清单中的参考版本；可以调速或循环播放 |
| 查看频谱 | 在波形和频谱之间切换；频谱显示当前试听文件的真实采样 |
| 回听边界 | 单独听起点或终点两侧，也可播放整个保留区间 |
| 收紧静音 | 用检测到的首尾静音给出区间建议，回听后再保存 |
| 标记问题 | 在播放位置一键留下噪声、截断或失真批注 |
| 留下批注 | 按 M 聚焦批注输入，提交时使用当时的播放位置；点时间跳转，点文字修改内容和时间 |
| 确定区间 | 拖动波形两端，或用 `[` / `]` 标记当前播放位置 |
| 保存决定 | 通过、待处理或排除；“保存并继续”跳到当前搜索和筛选结果中的下一条待审音频 |
| 导出记录 | 导出通过项 CSV，或用 JSON 保存完整审核；两者都包含区间和批注 |

保存后可以撤销，之前的记录仍留在历史中。

审核历史按最新在前展示状态、分数、问题标记、保留区间与批注；可将旧版本载入为未保存的草稿，核对后再点击保存。现有未保存更改需要先确认放弃，载入不会直接覆盖已保存记录。

未保存的编辑会在**本标签页会话**中暂存一份刷新副本。正常保护状态以审核标题旁的“本页暂存”显示，可展开查看范围、时间或清除副本；只有待恢复或出现问题时才显示完整提示。刷新后需要主动选择恢复；恢复的仍是草稿，只有点击保存才写入审核历史。尚未添加或确认的时间批注也会保留，不会替你提交批注。

恢复会核对音频版本、原审核版本和完整原记录。记录已变化或内容不适用时，只能查看、复制或清除副本，不会自动覆盖新记录。清除副本不改变当前编辑，下一次编辑可以重新暂存。

刷新副本不包含音频文件或写入令牌，也不包含在工作区备份及导出中。它仅用于同一标签页、同一地址的刷新恢复；关闭标签页、浏览器清理或更换地址后不保证可恢复。存储不可用或数字输入尚无法完整读取时，会明确提示未受保护。请完成有效输入并保存，不要把刷新副本当作备份。

批量标记保留备注和分数；“通过”需要逐条决定。浏览器会记住播放位置、速度和音量，位置记忆可在帮助中关闭。

“保存并继续”只在当前搜索和筛选结果中查找其他待审项。当前结果没有其他待审项、但清单其他位置仍有待审项时，会停留在当前素材；保存后成功刷新清单并确认全清单没有待审项时，才显示完成页。

侧栏和命令面板中的“下一条待审”不受当前搜索和筛选限制，按整个清单的顺序查找，跳过已处理项，到末尾后从头继续。

批量选择可以跨搜索和筛选保留，操作区会显示总数及不在当前结果中的数量。“选择当前结果”只影响可见条目；“清除选择”会取消全部勾选，不改动当前审核草稿或筛选。每次最多处理 500 条，超过时会显示说明。

A/B 切换会保留当前位置和播放或暂停状态，加载期间仍可暂停。播放较短的参考版本时，循环范围只取其实际存在的部分；没有该区间时会暂停并提示，可以切回原音频、调整区间或关闭循环。

A/B 对照需要在[清单](docs/manifests.md)中指定参考版本。频谱最多分析试听文件的前 2 分钟，超过 32 MiB 的试听文件使用波形查看。自动检测只提供提示，不会替你打分或通过素材。

## 数据与升级

原音频只供读取，保留区间不会裁剪文件。数据库、审核历史和试听副本放在独立工作区。升级前停止旧服务，备份**整个工作区**，用应用原有虚拟环境安装新版，再指定原路径启动。各版变化和具体命令见[版本记录](docs/releases/README.md)。

音频或参考版本变化后，新版本重新进入待审。移动文件时建议使用清单中的稳定 ID。重叠区间和重复音频的统计规则见[时长与精度](docs/counting.md)。

分享导出前请检查内容。默认只省略专用的文件路径字段，不会隐藏 ID、标签或备注。清单未提供 ID 时会使用路径作为 ID，未提供标签时会沿用 ID，因此导出仍可能包含绝对路径。详见[导出与恢复说明](docs/manifests.md#export-and-restore)。

### Ogg 结束状态提示（本地候选版）

成功解码不代表原录音完整。Ogg 的“结束未确认”表示检查未确认流的结束，文件可能尚未结束或不完整，也可能是实时录制；“检查未完成”是另一种中性状态，表示无法作出判断。详情明确标出 A 或 B，B 单独出现提示也会进入“需关注”列表，每条素材只计一次。没有提示也不保证原录音完整。

这些提示不改变版本标识、候选资格、人工通过状态或试听能力。JSON 保留 A/B 的质量标记；CSV 不导出质量标记。检查有读取量和页数等上限，不解释音频编码或时间戳，详见 [Ogg 检查范围](docs/manifests.md#ogg-ending-advisories)。需要确认录音完整时，请与原始来源的预期时长或独立校验值核对。

MP3 新扫描还可对带正数 Xing/Info 帧数的受支持文件给出非阻断提示：帧数不同可能是不完整，也可能是元数据已过期；检查未完成不代表损坏。没有提示也不能证明完整，旧记录需重新扫描。缺少/零帧数及不支持的初始格式不增加待关注项，详见 [MP3 检查范围](docs/manifests.md#mp3-frame-count-advisories)。

MP4/M4A 新扫描可对受支持文件给出非阻断的容器范围提示：声明范围超出可用文件可能是不完整，也可能是元数据不一致；检查未完成是中性提示。没有提示不证明完整，正在写入的文件可能本就未完成。旧记录需重新扫描，CSV 不包含质量提示。详见 [MP4 检查范围](docs/manifests.md#mp4-container-extent-advisories)。
