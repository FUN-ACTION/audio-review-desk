# Audio Review Desk 0.7.1

2026-10-27 · [下载本版](https://github.com/FUN-ACTION/audio-review-desk/releases/tag/v0.7.1) · [全部版本](README.md)

## 本版变化

修复时间批注的键盘操作：编辑后按 Ctrl / ⌘ Enter 保存，焦点会回到对应批注，便于继续回听或修改。修改时间导致排序变化时，也会跟回同一条批注。保存期间如果已经转到其他控件，应用不会把焦点抢回来。

本版保留 [0.7.0 的字体、布局、播放记忆与检索改进](0.7.0.md)。录屏文件保持不变。

## 安装与升级

1. 停止旧服务，备份**整个工作区目录**，包括数据库和试听缓存。
2. 解压 0.7.1 源码，或下载本版 wheel。使用应用原有虚拟环境里的 Python 安装，不需要训练环境。
3. 在新源码目录执行 `python -m pip install --upgrade .`，或把 `.` 换成本版 wheel 的完整路径。
4. 指定原工作区的完整路径启动，再刷新浏览器。

Windows 示例：

```powershell
& 'C:\path\to\app\.venv\Scripts\python.exe' -m pip install --upgrade .
& 'C:\path\to\app\.venv\Scripts\python.exe' -m audio_review_desk serve --workspace 'D:\path\to\original-workspace' --open
```

macOS / Linux 使用原环境的 `.venv/bin/python`。首次安装见[安装说明](../installation.md)。普通 PCM WAV 不需要额外音频库；其他格式需要 FFmpeg 与 ffprobe。

## 旧工作区

数据库、审核键和历史继续有效。本版不删除表，也不迁移音频。批注编辑仍使用已有的 `markers` 字段；播放偏好只保存在当前浏览器，不写入审核历史。更换浏览器或端口后，偏好需要重新设置。

从 0.2 开始，Windows 启动器默认使用 `review-workspace`，0.1 示例使用 `.ard-demo`。打开了新目录时，旧数据仍在原处。要回到旧工作区，请指定原路径：

```sh
audio-review-desk serve --workspace .ard-demo --open
```

0.1 导入的来源可能需要重新导入一次，“重新扫描”才会可用。0.2 起才记录集合成员关系；早期行没有集合标记，首次追加重扫会保留无法确认归属的旧行。要刷新整个活动列表，可在导入时关闭“追加到素材库”；这只替换当前列表，不删除历史。

旧页面向新版服务保存审核时，省略 `markers` 会保留已有批注。退回 0.4 或更早的服务后再保存，旧代码可能忽略批注字段，因此降级前也应保留完整备份。
