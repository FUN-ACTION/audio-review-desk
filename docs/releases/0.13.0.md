# Audio Review Desk 0.13.0

2026-10-29

## 本版变化

- 展示页重新设计：白色页面、轻量导航、统一字体层级，主视觉改用代码生成的立体声学环片。
- 听审台改为浅灰素材库、深色音频画布和独立审核栏。重排导入、播放器、区间与保存控件。
- 新增频谱视图。读取当前试听 WAV 的真实采样，使用对数频率轴与固定 dBFS 色标；与波形共用播放位置和区间。
- 新增起点、终点和完整区间回听；按检测到的首尾静音调整区间，回听确认后再保存。
- 在播放位置一键标记噪声、截断和失真；增加本次保存统计和下一条待审入口。
- 展示页的 A/B、区间循环、时间批注均可操作，使用合成音频。示例批注仅保留在当前页面。

频谱最多读取 32 MiB、分析前 120 秒和最多 8 声道，超过限制可继续用波形听审。图形和声音的来源见[作品说明](../artwork.md)。

## 安装与升级

停止旧服务，备份**整个工作区目录**，包括数据库、审核历史和试听缓存。在应用原有虚拟环境中安装新版，再指定原工作区启动：

```sh
python -m pip install --upgrade ./audio_review_desk-0.13.0-py3-none-any.whl

audio-review-desk serve --workspace "原工作区的完整路径" --open
```

从源码安装时，在解压目录执行 `python -m pip install --upgrade .`。Windows 的 Python 位于原环境的 `.venv/Scripts/`，macOS / Linux 位于 `.venv/bin/`。需要 Python 3.11 或更新版本；普通 PCM WAV 直接可用，其他格式需 FFmpeg 与 ffprobe。

## 旧工作区

本版不移动原素材，也不删除数据库表。使用原工作区路径启动，已有审核键、评分、保留区间、批注和历史继续有效。

`review-workspace` 从 0.2 开始成为 Windows 默认目录；0.1 的示例目录是 `.ard-demo`。打开早期工作区时，指定其原路径：

```sh
audio-review-desk serve --workspace .ard-demo --open
```

0.1 界面导入的来源可能需要重新导入一次，才能重新扫描。早期条目没有集合标记，首次追加重扫会保留无法确定归属的旧行；替换导入只刷新当前列表，不删除审核历史。

旧页面保存时省略时间批注会保留已有批注。0.4 及更早的服务可能忽略这些字段，降级前请另存完整工作区。

播放偏好只保存在当前浏览器，不写入审核历史。换浏览器或端口后需要重新设置。
