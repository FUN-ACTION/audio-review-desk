# Audio Review Desk 0.4.0

2026-10-26 · [下载本版](https://github.com/FUN-ACTION/audio-review-desk/releases/tag/v0.4.0) · [全部版本](README.md)

## 本版变化

空素材库直接提供文件夹与清单两个入口，不再显示空统计和重复的导入按钮。支持本机选择窗口，也可以填写路径。波形可以放大到 8×、平移和查看保留区间；两端边界支持拖动及方向键微调。调整后的区间仍需保存，不会裁剪原文件。

界面改为更克制的黑色主按钮与灰绿色波形，统一字号、间距和动作名称。首次进入、导入选项和弹窗使用连续的过渡；拖动与定位即时响应。README 改写为操作说明，各版本的更新与升级步骤各自归档，打包时检查是否齐全。

## 安装与升级

1. 停止旧服务，复制备份**整个工作区目录**，包括数据库和试听缓存。
2. 解压 0.4.0 源码，或下载本版 wheel。使用这个应用原有虚拟环境里的 Python 安装；不要切换到训练环境。
3. 从新源码目录执行 `python -m pip install --upgrade .`，或把 `.` 换成本版 wheel 的完整路径。
4. 指定原工作区路径启动，再刷新浏览器。相对路径按启动时的目录解析；升级时建议使用完整路径。

Windows 不必激活虚拟环境，可以直接执行：

```powershell
& 'C:\path\to\app\.venv\Scripts\python.exe' -m pip install --upgrade .
& 'C:\path\to\app\.venv\Scripts\python.exe' -m audio_review_desk serve --workspace 'D:\path\to\original-workspace' --open
```

macOS / Linux 使用原环境的 `.venv/bin/python`。首次安装见 [安装说明](../installation.md)。普通 PCM WAV 不需要额外音频库；FLAC、MP3 等格式需要 FFmpeg 与 ffprobe。

## 旧工作区

现有数据库和审核键继续有效，升级不删除表，也不清空审核历史。

从 0.2 开始，Windows 启动器默认使用 `review-workspace`，0.1 示例使用 `.ard-demo`。启动器打开新目录不代表旧数据丢失。要回到旧工作区，请指定原路径：

```sh
audio-review-desk serve --workspace .ard-demo --open
```

0.1 导入的来源可能需要重新导入一次，“重新扫描”才会可用。从 0.2 起才记录集合成员关系；早期行没有集合标记，首次追加重扫会保留无法确认归属的旧行。要刷新整个活动列表，可在导入时关闭“保留已有素材”；这只替换当前列表，不删除历史。
