# Audio Review Desk 0.1.0

2026-10-26 · [下载本版](https://github.com/FUN-ACTION/audio-review-desk/releases/tag/v0.1.0)

## 本版变化

- 首次提供独立应用，可从目录或清单载入音频，检查解码、电平、静音和 PCM 重复内容。
- 加入 A/B 参考试听、评分、问题标记、保留区间和审核历史。记录可以导出为 JSON；音频版本变化后需重新审核。
- 提供中英文界面、命令行、Windows 启动器和生成信号示例。

## 安装与升级

停止旧服务，备份**整个工作区目录**，包括数据库和试听缓存。激活应用原有虚拟环境后安装本版，再指定原工作区启动：

```sh
python -m pip install --upgrade ./audio_review_desk-0.1.0-py3-none-any.whl
audio-review-desk serve --workspace "原工作区的完整路径" --open
```

从源码安装时，在解压目录执行 `python -m pip install --upgrade .`。Windows 的 Python 位于原环境的 `.venv/Scripts/`，macOS / Linux 位于 `.venv/bin/`。本版需要 Python 3.11 或更新版本；普通 PCM WAV 可直接读取，其他格式需 FFmpeg 与 ffprobe。

## 旧工作区

工作区与音频目录分开保存，原音频只供读取。审核记录、保留区间和试听副本写入工作区，不会裁剪原文件。音频或参考版本变化后，片段需要重新审核。

本版 Windows 示例使用 `.ard-demo`。重新打开已有记录时，请给 `--workspace` 传入原目录，避免误开一个新的空工作区。

## 验证

发布时记录：40 项 Python 测试、3 项前端测试通过，7 项 CI 任务通过。独立安装 wheel 后检查播放、保存和并发修改提示。

验证使用生成信号和独立工作区，未打包私人录音或模型。
