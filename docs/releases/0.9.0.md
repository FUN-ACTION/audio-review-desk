# Audio Review Desk 0.9.0

2026-10-27 · [下载本版](https://github.com/FUN-ACTION/audio-review-desk/releases/tag/v0.9.0)

## 本版变化

- 展示页首屏改为程序生成的三维连接件，可推开、拖动和切换配色；试听按钮播放生成乐句。
- 录屏随滚动展开，由蓝色预览过渡到彩色画面；完整录像仍支持播放、暂停和进度拖动。沿用原有六段中英文录屏。
- 加入卡片菜单，展示页英文改用 Inter，中文保留 MiSans。手机和减少动态效果模式使用普通视频画面，图形不可用时显示备用图。
- 明确静态资源的文件类型，修复部分 Windows / Python 3.11 环境下 WebP 类型返回错误的问题。审核功能和工作区格式不变。

## 安装与升级

停止旧服务，备份**整个工作区目录**，包括数据库和试听缓存。激活应用原有虚拟环境后安装本版，再指定原工作区启动：

```sh
python -m pip install --upgrade ./audio_review_desk-0.9.0-py3-none-any.whl
audio-review-desk serve --workspace "原工作区的完整路径" --open
```

从源码安装时，在解压目录执行 `python -m pip install --upgrade .`。Windows 的 Python 位于原环境的 `.venv/Scripts/`，macOS / Linux 位于 `.venv/bin/`。本版需要 Python 3.11 或更新版本；普通 PCM WAV 可直接读取，其他格式需 FFmpeg 与 ffprobe。

## 旧工作区

安装应用不会搬动素材。重新启动时指定原工作区，已有审核和历史继续保留。`review-workspace` 从 0.2 开始成为 Windows 默认目录；0.1 的示例目录是 `.ard-demo`，旧记录仍在原处：

```sh
audio-review-desk serve --workspace .ard-demo --open
```

0.1 导入的来源可能需要重新导入一次，才能重新扫描。早期行没有集合标记，追加重扫会保留无法确认归属的旧行；替换导入只刷新当前列表，不删除历史。

旧页面保存时省略时间批注会保留已有批注。0.4 及更早的服务可能忽略这些字段，降级前请另存完整工作区。

播放偏好只保存在当前浏览器，不写入审核历史。换浏览器或端口后需要重新设置。
