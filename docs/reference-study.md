# 参考站交互拆解

2026-10-27 检查了 [Lusion 首页](https://lusion.co/) 的交互、字体与公开脚本，供 0.9 的页面研究使用。主要入口是[页面脚本](https://lusion.co/_astro/hoisted.CUO_IjfL.js)和[样式表](https://lusion.co/_astro/about.CNa9RfUh.css)。这些地址带构建指纹，参考站更新后可能失效。

## 实时场景与拖动

研究时，参考站首屏物体会响应指针，也能被拖住；点击会改变配色并产生一次冲量。该场景使用 WebGL、射线投影和简化碰撞。

本项目 0.9 用距离场生成带孔连接件。0.11 保留场景布局和拖动方式，将物体换成自行构造的四分音符、八分音符、连音和谱号。音符表面有圆角与厚度，使用不透明的象牙白、炭黑和钴蓝材质。网格、曲线和备用 SVG 均在本仓库生成。

指针投影到世界坐标后，拖动会保留抓取点相对物体中心的偏移，再转换到场景局部坐标。碰撞使用近似体积，并非精确网格接触。相机与摆放范围按容器尺寸调整，减少窄屏裁切。

## 字体与比例

研究时参考页加载 Aeonik，主标题使用常规字重。在 1280 像素视口下，大标题约为 128 像素、行高 128 像素、字距 −2.56 像素；首屏说明约为 32/35.2 像素，小按钮约为 14 像素。这些是当时的观察值。

0.11 恢复本地 Inter 与 MiSans 的搭配，以字号、字距、留白和对齐区分层级。中文使用未经修改的 MiSans Regular，不合成粗体。参考站的 Aeonik 文件没有随项目分发。

## 滚动与画面

0.9 曾研究参考站视频预览的弯曲展开：分段网格按位置延迟，最终回到矩形。本项目当时以自己的 `reel-warp.js` 顶点着色器实现类似过程。

0.11 的展示页已移除视频与软件操作示意。首屏之后的三块画面由 `music-art.js` 和 `music-shader.js` 生成，围绕曲线、流动形体与闭合环路展开，使用本项目自己的网格、材质和着色器。减少动态效果时保持静止；`?graphics=off` 使用静态图与 SVG。旧视频变形模块不再由当前展示页导入。

## 菜单

0.9 的研究还参考了右上角小卡片菜单、文字滚动与双圆点旋转。页面缓动采用 `cubic-bezier(.35,0,0,1)`，菜单采用 `.4,0,.1,1`。本项目用原生 Web Animations 控制进入与离开，打断时从当前显示状态继续。章节链接将焦点移到目标章节。

## 来源

参考站公开脚本用于分析，没有作为项目源码打包。音符、物理计算、音乐画面、着色器、菜单控制器和页面内容均由本项目实现。Three.js 按 MIT 许可分发，版本与构建记录位于 `scripts/scene-build`。

六段历史工作台录像在 0.10 重新录制，使用生成的测试信号；其来源、时间与文件摘要保留在[媒体记录](showcase-media.md)。这些录像没有在 0.11 展示页加载。项目不分发参考站的模型、贴图、影片、照片、标志或专有字体。
