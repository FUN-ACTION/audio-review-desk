# 参考站交互拆解

2026-10-27 检查了 [Lusion 首页](https://lusion.co/) 的实际交互、字体与公开脚本。主要入口为 [页面脚本](https://lusion.co/_astro/hoisted.CUO_IjfL.js) 和 [样式表](https://lusion.co/_astro/about.CNa9RfUh.css)。这些地址带构建指纹，参考站更新后可能失效。

## 首屏是实时场景

画面里的物体会被指针推动，也能被拖住。点击会改变配色并产生一次冲量。它使用 WebGL、射线投影和简化碰撞，并不是一段循环播放的视频。

本项目用带孔管件的距离场生成网格，再分成白、黑、蓝和少量透射材质。指针位置投影到世界坐标；拖动物体时保留抓取点相对中心的偏移，并转换到场景局部坐标，避免按下后物体突然跳到光标中心。碰撞只用近似体积，不是精确网格接触。

## 字体与尺寸

参考页实际加载 Aeonik，主标题通常用常规字重。1280 像素视口下检查到的大标题约128像素、行高128像素、字距−2.56像素；首屏说明约32/35.2像素。小按钮约14像素。差异来自比例、字距和留白，而不是把每一段文字加粗。

本项目继续使用本地已有的 Inter 常规字重与 MiSans。标题大小随视口变化，中文不模拟粗体。Aeonik 没有随本项目分发。

## 滚动与视频

参考页的视频是一张分段网格：不同位置稍有延迟，展开过程中有弯曲，末端回到矩形。预览同时从蓝色调转回原色，展开后保留一段滚动停留区。

本项目的 reel-warp.js 使用32×32平面与自己的顶点着色器，实现这个过程。滚动仍由浏览器控制；视觉进度以每秒系数12的指数阻尼跟随。减少动态效果、窄屏和节流模式直接使用普通视频。`?graphics=off` 可关闭展示页的两个 WebGL 场景，录屏仍然可以播放。

## 菜单

参考站使用右上角两张小白卡片，而不是铺满屏幕的导航层。卡片进入与离开带轻微旋转，动画可以中途反转。按钮的文字向上滚动，双圆点旋转。

页面过渡参考了其 `cubic-bezier(.35,0,0,1)`；菜单使用 `.4,0,.1,1`。本项目用原生 Web Animations，在打断时读取当前的显示位置继续动画。关闭菜单立即归还焦点，点章节链接则将焦点移到目标章节。

## 实现与来源

公开脚本只用于分析，未作为应用源码打包。本站的网格、物理计算、着色器、菜单控制器和页面内容均在本仓库。Three.js 按 MIT 许可分发，版本及完整性记录在 scripts/scene-build；六段工作台视频由本项目录制，继续沿用0.8的原文件。没有使用参考站的模型、贴图、影片、标志或字体文件。
