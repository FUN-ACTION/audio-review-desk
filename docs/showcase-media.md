# Website media

This source candidate uses a code-generated three-dimensional acoustic form and a browser listening desk. It contains no active operation recording or embedded video. The [published website](https://fun-action.github.io/audio-review-desk/tour/) may still serve the earlier design; this document is not a deployment record.

## Current presentation

signal-stage.js creates the geometry, perspective and lighting at runtime using the bundled Three.js renderer. Geometry and shaders are not downloaded from a third-party website. The original project layout and implementation are described in [artwork](artwork.md).

The examples use a deterministic, original twelve-second phrase generated by studio-signal.js. The A/B variants share timing and have different timbres. Range sliders change the audible interval; timestamped notes can be added, selected and deleted. Example notes are temporary and disappear when the page is refreshed.

A local song can be selected for the main visual and the listening/range/note panels. music-player.js and local-review.js use browser object URLs and do not upload or package that file. Previous object URLs are released on replacement, reset or disposal; cancelled and failed candidate loads are also retired. Audio begins only after an explicit play action.

The browser preview accepts one file up to 64 MiB and one hour, subject to the browser's format support. It displays a time ruler rather than fabricating local waveform data. Local B is disabled because there is no second file. Waveform/spectrum analysis, two-file A/B and saved review history remain in the full local workspace. Local range/notes export uses its own clearly identified JSON schema, and does not write a workspace review.

## Retained assets

The three 0.12 generated PNGs, earlier graphics experiments and six older bilingual MP4 recordings remain for reproducibility. The active page does not import or display them. The recordings used generated test signals; their original hashes and capture details remain in [the historical manifest](showcase-media.json).

The static builder copies the source page, fonts, code and retained assets into a new output directory. It never opens a workspace, includes a selected song or modifies source audio. Build with: python scripts/build_showcase.py --output /new/static-output
