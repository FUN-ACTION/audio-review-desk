# Audio Review Desk

[English](../README.md) · [安装](installation.md) · [清单格式](manifests.md) · [更新记录](../CHANGELOG.md)

用来整理音频素材的本地听审工具。导入目录后，可以筛出异常文件、对照参考音频、记录问题，再导出审核结果。

![素材列表、试听与审核区](screenshot-zh-CN.png)

截图使用程序生成的测试信号，仓库不附带真人录音。

## 启动

Windows 下载并解压[最新源码包](https://github.com/FUN-ACTION/audio-review-desk/releases/latest)，双击 `start-windows.cmd`。需要 Python 3.11 或更高版本，启动器会建立独立环境，第一次打开是空工作区。

点击右上角 **导入素材**，填写本机的音频目录路径。如果已有切句、来源时间或参考音频，选择 **CSV / JSON 清单**。默认保留其他目录的素材；取消勾选才会替换当前列表。

导入过程中会显示当前文件与进度，可以停止。清单在全部检测完成后一次更新，失败或取消不会留下半份清单。

## 日常操作

| 想做什么 | 操作 |
| --- | --- |
| 找到无法解码、过低音量或接近满幅的文件 | 左侧筛选“需关注” |
| 对照处理前后音频 | 点击 A / B，切换时保留播放位置 |
| 反复听一个字或边界 | 拖动波形定位，设置起止时间，开启“循环”，调整速度 |
| 逐条审核 | 选择状态，填写评分和备注，“保存并继续” |
| 一批素材需要重做 | 勾选文件，批量标记“待处理／排除／待审” |
| 刚才标错了 | “撤销上次审核”，原记录仍留在历史中 |
| 导出通过的片段清单 | 导出 → 通过的素材 · CSV |
| 隐藏其他面板，专心听 | 右上角“专注试听”，或按 F |

空格播放，B 切换对照，J/K 切换片段，1–4 选择审核状态，`[` / `]` 取当前播放位置作为起止点，Ctrl+Enter 保存。输入备注时不会触发这些播放快捷键。

## 原素材与记录

源音频保持只读，数据库和试听副本保存在独立工作区。建议起止时间只影响记录和统计，不会真正裁剪文件。

音频内容、参考音频或来源区间变化后，新版本从待审开始；旧版本保留自己的评分。批量操作保留备注和分数，不批量生成“人工通过”。同时打开两页时，旧页面不能覆盖另一页刚保存的审核。

WAV 不需要额外运行库。FLAC、MP3 等格式需要可选的 FFmpeg 与 ffprobe。[安装与故障处理](installation.md)

## 0.3 更新

这一版重新设计了听审工作台：本地字体、自定义播放器、波形定位、专注试听和浅／深色外观。A/B、弹层和保存反馈加入了连贯过渡，也支持系统的“减少动态效果”设置。导入、批量审核、撤销和 CSV 导出仍可照常使用。[设计说明与参考](design.md)

原有 0.1 工作区可以继续使用，升级前先停止旧服务并备份工作区。项目仍在早期，欢迎带复现步骤反馈实际使用问题。
